# Code of conduct

This repository has one maintainer and no community, so adopting a governance
document written for a foundation project would be theatre. Here is the actual
standard, which is short because it can be.

**Be straightforward and be kind.** Disagree with the code, the design or the
decision — not with the person. Assume the other party is competent and acting
in good faith until that is genuinely untenable.

**Harassment, discrimination and personal attacks are not tolerated** in issues,
pull requests, commit messages or any other space attached to this project.
Neither is deliberately wasting someone's time.

**Bring evidence.** This repository has a standing rule that every claim is an
observation or is labelled as unverified
([ADR 0005](docs/adr/0005-measure-never-estimate.md)). The same applies to
review comments: "this is slower" is worth more with a measurement, and "this
is wrong" is worth more with the failing case.

## Enforcement

Report a problem to **kalebkougl@gmail.com**. The maintainer decides, and the
available responses are asking someone to stop, editing or deleting a comment,
closing a thread, and blocking an account. Reports are handled privately.

Since the maintainer is also the sole enforcer, that is a conflict of interest
worth stating plainly rather than hiding behind procedure: if the problem is the
maintainer, there is no appeal here. Take it to GitHub.
